# Analysis drafts (Czech)

> **uuApp is the source of truth.** Business Requests, Business Model and Application Model are submitted and graded in uuApp (links in `README.md`).
> What is here is a work-in-progress draft – it may be outdated or not approved.

Anyone can draft content here with AI and then move it to uuApp. How: [`docs/ai/priprava-pro-uuapp.md`](../ai/priprava-pro-uuapp.md). Drafts are written in Czech, like the uuApp documents.

| Folder | Content |
|---|---|
| `user-stories/` | user stories (Business Requests › User story) |
| `business-use-cases/` | business use cases (Business Model) |
| `commands/` | endpoints (Application Model › Command List) |

Every file starts with the line `> Draft – zdroj pravdy je uuApp.`
